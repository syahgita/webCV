Development

Website ini dikembangkan dengan alur berikut

  1. Repositori diinisialisasi dengan git init di folder proyek.
  2. Perubahan dikembangkan per bertahap: struktur HTML, gaya CSS, interaksi JavaScript, lalu dokumentasi — setiap tahap menjadi satu commit terpisah dengan pesan berformat feat:, style:, atau docs:.
  3. Setiap tahap diuji di server lokal (mis. python -m http.server) sebelum di-commit.
  4. Repositori di-push ke GitHub (git push -u origin main).
  5. Halaman diaktifkan lewat GitHub Pages: Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save.

Deploy

GitHub Pages otomatis mempublikasikan isi main sebagai situs statis. Setiap perubahan baru tampil setelah di-push ke main, sehingga tidak perlu build step.
